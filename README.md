# OTIMIROUTER: UM SISTEMA VOLTADO À MINIMIZAÇÃO DAS ROTAS

Software desenvolvido para o Trabalho de Conclusão de Curso (TCC) apresentado como exigência para obtenção do título de Especialista em Desenvolvimento Full Stack do Instituto Federal do Sudeste de Minas Gerais - Campus Manhuaçu 

[Marcelo Tomaz Cipriano] - [2026]:

### 🎯 Objetivo
O **OtimiRouter** tem como propósito otimizar a logística de transportes através da roteirização inteligente. O sistema visa reduzir custos operacionais e o tempo de deslocamento, calculando as rotas mais eficientes entre múltiplos pontos geográficos, integrando serviços de geolocalização para oferecer uma solução prática e escalável para gestão logística.

 ## Guia de Instalação
Siga os passos abaixo para configurar o ambiente de desenvolvimento em sua máquina local.

### Pré-requisitos
*   **Node.js** (v20 ou superior)
*   **MySQL**

### Passo a Passo

1.  **Clonar o repositório:**
    ```bash
    git clone https://github.com/pos-FullStack/trabalho-de-conclus-o-de-curso-MarceloTmaz

    cd otimirouter
    ```

    2.  **Instalar as dependências:**
    ```bash
    npm install
    ```
    
    3.  **Iniciar a aplicação:**
    ```bash
    npm start
    ```
    Acesse a aplicação em: `http://localhost:3000`
